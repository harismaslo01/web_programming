# Update the AI log

1. Open docs/AI_LOG.md. If it does not exist, create it with the heading "# AI Log".
2. Find the section of the current milestone (for example "## Milestone 3"). Create it if it is missing.
3. Ask the student which tool and model they used, what the task was and what the main prompt was.
4. Add the tool, task, main prompt (quoted), what was generated, and what the student kept,
   changed or rejected to the milestone section.
5. Ask the student whether the AI was wrong in this task. If yes, add an "Incorrect case" entry:
   what was wrong, how they noticed it, how they fixed it. Every milestone needs at least 2.
6. Never invent prompts, tools or mistakes. If something is unclear, ask.
7. Show the new entry and wait for confirmation before saving.
